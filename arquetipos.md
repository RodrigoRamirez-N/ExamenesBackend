# Tipos de personalidad Jung / MBTI

| Código | Nombre | Descripción |
|---|---|---|
| INTJ | El Analista | Analítico, independiente, visionario, metódico y tenaz; enfocado en sistemas, lógica y planificación. |
| INTP | El Arquitecto | Curioso, objetivo, conceptual y flexible; le gusta resolver problemas abstractos y entender cómo funcionan las cosas. |
| ENTJ | El Comandante | Decisivo, organizado, ambicioso y lógico; suele liderar equipos y empujar objetivos grandes. |
| ENTP | El Inventor | Ingenioso, debatiente, adaptable y audaz; genera ideas nuevas y disfruta retar lo establecido. |
| INFJ | El Visionario | Empático, reflexivo, idealista y determinado; busca significado y entiende bien a los demás. |
| INFP | El Sanador | Creativo, introspectivo, empático y fiel a sus valores; suele conectar con causas humanas y expresión artística. |
| ENFJ | El Profesor | Carismático, atento, organizado e idealista; influye positivamente en otras personas y grupos. |
| ENFP | El Comunicador | Entusiasta, imaginativo, cálido y espontáneo; inspira a otros con energía e ideas. |
| ISTJ | El Inspector | Disciplinado, pragmático, estructurado y preciso; destaca por su orden y confiabilidad. |
| ISFJ | El Protector | Cuidadoso, servicial, responsable y leal; suele apoyar y cuidar a los demás. |
| ESTJ | El Supervisor | Líder responsable, realista y disciplinado; orientado a reglas, organización y ejecución. |
| ESFJ | El Buen Vividor | Tradicional, abierto, emotivo y sociable; valora la armonía y el apoyo social. |
| ISTP | El Artesano | Observador, práctico, autónomo e ingenioso; resuelve problemas con habilidad técnica. |
| ISFP | El Artista | Sensible, creativo, adaptable y espontáneo; valora la expresión personal y lo estético. |
| ESTP | El Legionario | Enérgico, directo, realista y orientado a la acción; responde rápido y se adapta bien a entornos dinámicos. |
| ESFP | El Actor | Sociable, cálido, expresivo y optimista; disfruta el presente y conecta fácilmente con otros. |

# Tipos de aprendizaje VARK

|---|---|---|
| V | Visual | Aprende mejor con imágenes, diagramas, mapas, colores y representaciones gráficas. |
| A | Aural / Auditivo | Aprende mejor escuchando explicaciones, discusiones, podcasts o clases habladas. |
| R | Read/Write | Aprende mejor leyendo y escribiendo; prefiere textos, apuntes, listas y resúmenes. |
| K | Kinestésico | Aprende mejor con práctica, movimiento, experimentos y experiencias reales. |
